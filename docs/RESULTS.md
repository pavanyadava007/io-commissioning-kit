## Definitions

- Detected: at least one point involved in the fault is reported as failed.
- Classified: every point involved is failed with the right cause; for a swap both points must also name each other.
- False alarm: a point with no injected fault is reported as failed.
- Kit: 5 injection steps (0/25/50/75/100 %) with 3 readings each, cross-talk check on all channels of the same type, DI/DO in both states.
- Naive: one reading at 50 % per analog point, one state (closed / ON) per digital point, no cross-talk check, pass/fail only.
