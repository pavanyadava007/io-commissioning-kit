io-commissioning-kit

I/O-list-driven commissioning toolkit for a simulated instrumentation rack of a laser amplifier test bench. By Pavan Yadava Annappa.

Everything on this page is simulated. The rack, the field devices, the wiring faults and the OPC UA server are a local Python simulation. No real hardware, PLC or plant data is involved. The interlock logic is a test harness, not a safety function.
